# Trace Studio — Landing Page

> Plataforma web oficial de **Trace Studio**: Software a Medida, Automatizaciones & Datos.

Desarrollada con **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS**, **Three.js** (WebGL con shaders GLSL circulares) y **Framer Motion** con estética **iOS Liquid Glass**.

## 🚀 Puesta en marcha local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## 🛠️ Scripts disponibles

* `npm run dev` — Servidor de desarrollo con Turbopack.
* `npm run build` — Compilación y validación de tipos para producción.
* `npm run start` — Iniciar servidor de producción.
* `npm run lint` — Verificación de reglas ESLint.
